Connecte ton plan

Ton plan et tes séances sont gardés dans ton dépôt privé GitHub. Personne d'autre ne les voit. À faire une seule fois par appareil :

  1. Crée un compte GitHub (gratuit) si tu n'en as pas.
  2. Crée un dépôt privé nommé journal-course (laisse-le vide).
  3. Crée un jeton « fine-grained » : Repository access → Only select repositories → journal-course ; Permissions → Contents → Read and write. Choisis une longue expiration.
  4. Colle le jeton ici. Il reste dans ce navigateur ; ne le partage avec personne.
Mon dépôt ne s'appelle pas « journal-course »
